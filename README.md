# Customer & Seller Portal

A PHP and MySQL-based web application developed as an academic project, providing separate portals for **customers** and **sellers**.

The application allows users to access different functionalities based on their role, with database connectivity handled through MySQL and phpMyAdmin.

## 🖥️ Project Overview

The application provides two main sections:

### 🛒 Seller Portal

A dedicated interface for sellers to manage their products and interact with the application as a seller.

### 👤 Customer Portal

A separate interface for customers to access customer-related functionality, including product purchasing and order-related operations.

## ✨ Features

* Separate Customer and Seller portals
* Customer registration and login
* Seller registration and login
* Product management for sellers
* Product purchasing functionality
* Order management
* MySQL database integration
* PHP-based server-side processing
* Local development using XAMPP

## 🛠️ Technologies Used

* **PHP**
* **MySQL**

* **CSS**
* **Bootstrap**

## 📁 Project Structure

The project contains PHP files for customer and seller authentication, portals, product management, purchasing, and order management.

The repository also includes:

```text
sellerdb.sql
```

which contains the database structure/data required to recreate the project's MySQL database.

## ⚙️ How to Run

### 1. Install XAMPP

Install XAMPP with Apache and MySQL.

### 2. Clone the repository

```bash
git clone https://github.com/itsswastik22-rgb/customer-seller-portal.git
```

### 3. Move the project

Place the project folder inside:

```text
C:\xampp\htdocs\
```

### 4. Start XAMPP

Start:

* Apache
* MySQL

### 5. Create the database

Open:

```text
http://localhost/phpmyadmin/
```

Create a database named:

```text
sellerdb
```

Import the provided:

```text
sellerdb.sql
```

file into the database.

### 6. Run the application

Open:

```text
http://localhost/customer-seller-portal/
```

## 📸 Application

The application starts with separate entry points for the **Seller Portal** and **Customer Portal**.
